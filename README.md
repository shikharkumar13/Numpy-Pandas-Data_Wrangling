# Data Manipulation
 
A numbered series of Python for data manipulation and data wrangling notebooks, each one built around a single topic and meant to be worked through hands-on.
 
## About this repository
 
Every notebook here focuses on one topic in depth, with real code you can run and edit as you go. Alongside the notebooks, each topic also has a **companion article**, a longer, more detailed write-up that walks through the same material with fuller explanations, worked examples, and visual diagrams, for anyone who wants more context than the notebook alone provides.
 
The notebooks are the place to practice. The articles are the place to actually understand *why* the code works the way it does.
